The foundation is laid: Psanctuary Church gets a home on GitHub

TL;DR: Psanctuary Church now has a quiet, honest home on GitHub: an organization profile, an entry portal at psanctuarychurch.github.io, and this changelog and library. None of it replaces psanctuary.org. It's a place to keep the church's technical work in the open as it grows.
Read the full story

What was set up

  • An organization profile. The public face of psanctuarychurch on GitHub, written from psanctuary.org’s own words rather than guesses.
  • A members-only space, for coordination that shouldn’t be public.
  • An entry portal at psanctuarychurch.github.io that points visitors to psanctuary.org, this changelog, and the library.
  • This changelog and library. The source behind them stays private, and only the finished pages are published, so drafts and internal notes can’t slip out by accident. The library has a short write-up on how that works.

Why there are two organizations

The church holds two GitHub organizations, psanctuarychurch and psanctuary, so the name stays safe while the work takes shape. Both got the same setup on the same day, so either one can take the lead later without starting over.

What isn’t decided yet

  • Which of the two organizations becomes the main home.
  • What the first real project here will be.

When either of those is settled, it’ll be the next entry here.
